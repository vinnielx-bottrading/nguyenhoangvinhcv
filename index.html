How I build

01Design reasoning

Start from the user's job, then shape the interface. Kafka X modules mirror how a marketing team actually works: plan → execute → measure. Games get onboarding, hints and difficulty assists so players never feel lost.

02Coding

Build and ship solo with HTML/CSS/JS, Canvas, Supabase and Firebase, deployed through GitHub and Vercel. Every product runs on desktop and mobile, with cloud accounts and synced progress.

03Creative ideation

Turn a concept into a world people want to enter: a Kafka‑inspired brand voice for a SaaS tool, a Vietnamese hero for an action game, a dinosaur hunt that teaches kids about nature.

04Problem solving

Trace issues to root cause and fix them for good. In Kafka X, a data‑loss bug came from oversized images and sync overwriting local work; I solved it with automatic image compression and merge‑based sync.
